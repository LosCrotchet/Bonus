# Bonus

Bonus 是一款使用两副扑克牌和一枚六面骰子的 2D 出牌游戏，使用 Godot 4.7 与 GDScript 开发。

## 当前状态

项目已经具备可运行的 2～4 人单机牌局，默认使用三人配置。当前版本实现两副共 108 张牌、17 张初始手牌、完整牌型与大小比较、跟牌、Pass、BONUS、万能牌多解选择与惩罚、牌堆回收、可替换 AI 和关键节点结算。

## 开发环境

- Godot 4.7.1 或同一兼容版本
- GDScript
- 首个版本以桌面平台和鼠标操作为目标

用 Godot 编辑器导入本目录中的 `project.godot` 即可打开项目。

运行项目后会直接进入 `features/game/game_scene.tscn`。轮到南家时点击骰子，再用鼠标选择手牌；“推荐”会选择一手合法牌。单击切换单张牌，按住左键划过多张牌可连续切换，右键可清空选择。顶部“设置”可调整玩家数量、游戏速度、分辨率、窗口模式和语言，也可新开牌局或退出游戏。

## 项目结构

| 目录 | 用途 |
| --- | --- |
| `app/` | 程序入口及顶层场景组合 |
| `assets/` | 项目实际使用的美术、音频、字体和主题资源 |
| `autoload/` | 少量跨场景服务 |
| `core/` | 不依赖界面、AI 或网络的游戏状态、规则和牌局流程 |
| `features/` | 主菜单、游戏、设置、教程等用户可见功能 |
| `ai/` | AI 接口实现与可替换策略 |
| `localization/` | Godot 翻译源文件与各语言资源 |
| `multiplayer/` | 联机协议、同步逻辑和传输适配器 |
| `shared/` | 多个功能共同使用的界面组件 |
| `tests/` | 单元测试与集成测试 |
| `docs/` | 工程文档，不参与 Godot 资源导入 |

完整说明见 [架构说明](docs/architecture.md)、[游戏场景开发路径](docs/game_scene_roadmap.md) 和 [AI 策略接口](docs/ai_strategy_api.md)。

## 资源与参考代码

- 游戏规则以项目外部维护的正式 Markdown 规则为唯一依据。
- 旧版本代码只用于了解已有功能，不复制其架构或实现。
- 扑克牌、骰子和筹码只从提供的 `Card_Game_GFX` 素材库中选取。仅将实际使用的文件复制到 `assets/art/`，不提交整套源素材库。

## 基本约定

- 文件、目录、变量和函数使用 `snake_case`。
- 类名、节点名和枚举名使用 `PascalCase`。
- 信号使用过去时命名，例如 `turn_started`、`card_played`。
- 新代码使用静态类型；公开接口必须写明参数和返回值类型。
- 场景专属脚本与场景放在同一功能目录。
- 不使用含义宽泛的全局 `manager` 保存牌局状态。

# Bonus

Bonus 是一款使用两副扑克牌和一枚六面骰子的 2D 出牌游戏，使用 Godot 4.7 与 GDScript 开发。

## 当前状态

当前版本为 `0.5.4`，已经具备主菜单、2～4 人单机规则配置和完整可玩的牌局。项目实现两副牌、逐张开局发牌、17 张初始手牌、自然大小王与可选万能牌、完整牌型比较、跟牌、Pass、BONUS、多解选择、牌型浏览、牌堆回收、可替换 AI、分层音频设置和关键节点结算。

当前构建暂不内置音效，仅保留 `Master`、`SFX` 和 `Music` 总线及对应音量设置。后续音效选材清单见 `docs/sound_cue_catalog.md`。

## 开发环境

- Godot 4.7.1 或同一兼容版本
- GDScript
- 首个版本以桌面平台和鼠标操作为目标

用 Godot 编辑器导入本目录中的 `project.godot` 即可打开项目。

运行项目后进入 `app/app.tscn` 主界面。选择“单人游戏”可设置人数和可选规则，再进入牌局。轮到南家掷骰时，点击 Header 之外的画面区域即可掷骰；“推荐”会选择一手合法牌。单击切换选择，按住左键划过多张牌可连续选择，右键清空选择。手牌始终自动排序；开启“双击过牌与出牌”后，双击空白区域可提交当前选择，未选牌时则直接过牌。

设置只在点击“应用”后生效，支持游戏速度、分辨率、窗口/全屏、中英文、状态提示、保守自动跳过和双击操作。“应用”不会关闭设置面板，关闭或点击面板外区域可返回牌局。编辑器运行时必须关闭 Game 窗口的嵌入模式，项目已将 `Embed Game on Next Play` 默认设为关闭，否则 Godot 不允许运行时调整窗口。牌局结束后可再来一把或返回主菜单。

## 项目结构

| 目录 | 用途 |
| --- | --- |
| `app/` | 程序入口及顶层场景组合 |
| `assets/` | 项目实际使用的美术、音频、字体和主题资源 |
| `autoload/` | 少量跨场景服务 |
| `core/` | 不依赖界面、AI 或网络的游戏状态、规则和牌局流程 |
| `features/` | 主菜单、游戏、设置、教程等用户可见功能 |
| `ai/` | AI 接口实现与可替换策略 |
| `localization/` | Godot 翻译源文件与各语言资源 |
| `multiplayer/` | 联机协议、同步逻辑和传输适配器 |
| `shared/` | 多个功能共同使用的界面组件 |
| `tests/` | 单元测试与集成测试 |
| `docs/` | 工程文档，不参与 Godot 资源导入 |

完整说明见 [架构说明](docs/architecture.md)、[游戏场景开发路径](docs/game_scene_roadmap.md) 和 [AI 策略接口](docs/ai_strategy_api.md)。

## 资源与参考代码

- 游戏规则以项目外部维护的正式 Markdown 规则为唯一依据。
- 旧版本代码只用于了解已有功能，不复制其架构或实现。
- 扑克牌、骰子和筹码只从提供的 `Card_Game_GFX` 素材库中选取。仅将实际使用的文件复制到 `assets/art/`，不提交整套源素材库。

## 基本约定

- 文件、目录、变量和函数使用 `snake_case`。
- 类名、节点名和枚举名使用 `PascalCase`。
- 信号使用过去时命名，例如 `turn_started`、`card_played`。
- 新代码使用静态类型；公开接口必须写明参数和返回值类型。
- 场景专属脚本与场景放在同一功能目录。
- 不使用含义宽泛的全局 `manager` 保存牌局状态。
